# Button

Button is a mobile commerce and affiliate attribution platform connecting publishers, retailers, advertisers, and creators. Its AI-driven intelligence platform routes users to the highest-converting destination, powering smart routing, in-app priority, privacy-safe first-party attribution, and the CuratedBy Button publisher tool.

For developers, Button exposes REST APIs for brand details, real-time affiliate offers, attributable link and shortlink generation, and billing/commission transaction reporting, plus native iOS and Android SDKs, merchant libraries, and signed transaction webhooks.
